# FlowBoard — Task 2: Dashboard + REST API

This folder evolves Task 1 by copying the FlowBoard dashboard into `frontend/` and adding the REST API in `backend/`.

- `frontend/` — FlowBoard dashboard (React + Vite + Tailwind). Run: `cd frontend && npm install && npm run dev`
- `backend/` — FlowBoard API (Express + Zod). Run: `cd backend && npm install && npm run dev` → http://localhost:5000

See `backend/README.md` for the full endpoint contract and `backend/postman_collection.json` for a one-click Postman import.

Live demo: https://flowboardy-task2.vercel.app (reads https://flowboardy-api.vercel.app/api — zero mock data)
